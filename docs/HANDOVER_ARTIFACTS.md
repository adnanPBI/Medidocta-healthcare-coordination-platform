# Handover artifacts in this repository

The repository commits the **editable text/source layer** of the Medidocta review so the demo and architecture can be inspected directly in GitHub and deployed without binary office-file dependencies.

Included:

- `public/deliverables/Medidocta_Technical_Review_Source.md`
- Editable CSV registers
- Mermaid source for architecture, domain relationship and booking transaction diagrams
- Release QA notes

The client-release DOCX/PDF/XLSX package remains the formatted handover representation produced from these sources. The live demonstrator is not the production MVP and does not claim real healthcare-data processing.
