# Editable source handover

This folder contains repository-native source artifacts from the Medidocta client-release review.

- `Medidocta_Technical_Review_Source.md` - master technical review source
- `registers/` - architecture, API, ownership, concurrency, RBAC, responsive, localization, Figma and decision registers
- `diagrams/` - Mermaid architecture/domain/booking sources
- `RELEASE_QA.md` - release QA summary

The interactive demo is a review demonstrator, not a production healthcare MVP. The formatted DOCX/PDF/XLSX files remain the formal client-delivery representations maintained outside the deployable source tree.
